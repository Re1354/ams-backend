Welcome to the Academic Management System API for DIU. This API provides access to scrapped questions and educational content with comprehensive filtering and search capabilities.

Interactive API documentation with try-it-out functionality

🚀 Features

  • 25+ Educational Questions
  • Multiple Subjects (Math, English, Physics, etc.)
  • Advanced Filtering & Search
  • Statistics & Analytics
  • RESTful API Design
  • CORS Support
  • Pagination Support
  • OpenAPI/Swagger Documentation

🔗 API Endpoints

GET /api/all-scrapped-questions/

Get all scrapped questions with filtering options

GET /api/questions-stats/

Get comprehensive statistics about questions

🔍 Query Parameters

  • subject - Filter by subject (e.g., Mathematics, English)
  • type - Filter by type (option, text)
  • semester - Filter by semester
  • search - Search in question text and subjects
  • page - Page number for pagination
